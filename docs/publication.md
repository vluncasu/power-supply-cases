# Versions and citation

Download the latest [print kits](https://github.com/vluncasu/power-supply-cases/releases/latest) for printing. To edit a specific revision, download the source archive from the same tagged release. For a reproducible reference, record the case name, release tag or Git commit, part file and relevant CAD report. SHA256SUMS identifies the case files in the repository. The release checksum file identifies its downloadable archives.

The third-party STEP reference used for the S-60-12 fit study is excluded from distribution. No reuse license has been selected for the geometry, code or documentation.
